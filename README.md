**ESG 신뢰 마케팅 전략**으로 연결한 데이터 기반 비즈니스 기획 프로젝트입니다.

## 📌 문제 정의

SSG 물류의 **배송 경로 비최적화**와 **PP센터 구조 비효율**이 불필요한 이동거리를 만들고,
이는 곧 **탄소 배출 증가**와 **ESG 신뢰 저하**로 이어진다. 이를 데이터로 진단하고,
경로 최적화 → 탄소 절감 → 마케팅 자산화의 흐름으로 해결한다.

**KPI**
- K1. 배송 이동거리 감소율 ≥ 20%
- K2. 배송 효율 개선율 ≥ 15%
- K3. 탄소 배출 감소량 정량화

## 📂 데이터 & 방법

- **분석 거점:** 이마트 가든파이브 PP센터 (37.4786°N, 127.123°E)
- **데이터:** 고객 50개 좌표 (문정·잠실·가락·장지동), `customers_clustered_50.csv`
- **거리 계산:** Haversine Formula (지구 곡률 반영)
- **알고리즘 비교:** Baseline(FIFO) · Nearest Neighbor(Greedy) · Clarke-Wright · OR-Tools · MST-DFS(Prim+DFS)

## 📊 핵심 결과

| 알고리즘 | 월간 이동거리 | 현재 대비 절감 | 차량 감소 |
|---|---|---|---|
| Baseline (FIFO) | 10,198 km | — | 기준 |
| Nearest Neighbor | 9,484 km | −7% | −5% |
| Clarke-Wright | 7,852 km | −23% | −17% |
| **OR-Tools** | **6,731 km** | **−34%** | **−22%** |

→ **OR-Tools** 채택: 거리 34%·차량 22% 감소, 시간 제약 지원, 무료 오픈소스로 SSG 적합성 최고.

## 🌿 탄소 절감 효과 (OR-Tools 기준)

- 월 **761 kg** · 연 **9.13톤** CO₂ 절감 = 30년생 소나무 약 **1,384그루**의 연간 흡수량
- 연료비 약 **707만원/년** 절감
- 산식: `절감 CO₂(kg) = 절감거리(km) × 0.085(L/km) × 2.582(kg CO₂/L)`
- 출처: 경유 배출계수 2.582 kg CO₂/L (한국기후·환경네트워크), 소나무 6.6 kg/그루·년 (국립산림과학원)

## 📣 ESG 신뢰 마케팅 전략

> "속도 경쟁이 아닌 신뢰 경쟁으로 — 검증 가능한 친환경 배송"

**4단계 프레임워크:** ① 물류 효율화(OR-Tools) → ② ESG 데이터화(탄소·소나무) → ③ 고객 접점 공시(앱 탄소 대시보드) → ④ 브랜드 신뢰("나무 심는 SSG")

고객 세그먼트(속도 우선형·친환경 가치형·신뢰 정확성형·비용 민감형)별 맞춤 메시지와 12개월 실행 로드맵(신뢰 기반 구축 → 참여 확산 → 브랜드 자산화) 포함.

**근거 데이터:** ESG 구매경험 27.7% (한경ESG 2025, N=3,000), ESG 추가지불 의향 73% (한국경제인협회 2025, N=1,000) — 친환경 배송을 브랜드 신뢰 자산으로 전환할 시장 근거.
